# Networking Fundamentals: How Machines Talk

A from-scratch, beginner-friendly project that demystifies networking by making every concept concrete with tiny Python programs and text diagrams. You start with what an IP address is and why machines need them, then build a layered mental model with the OSI and TCP/IP stacks, see how DNS turns names into addresses, and watch a real TCP connection get established with a Python socket. From there you learn ports as the way one host runs many services, subnetting and CIDR to carve up address space, how routers move packets between networks, and finally the troubleshooting toolkit — ping, traceroute, and netstat — mapped back to the layers so you can reason about *where* a problem lives. Each step adds or extends a small `netlab/` Python script you carry forward, so the abstract stack becomes runnable code.
